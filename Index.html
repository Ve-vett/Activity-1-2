1. Web Architecture Concepts

Client-Server Model


The Client (your browser) sends a request, and the Server returns the web page response.

DNS (Domain Name Server)


Translate human-friendly domain names (like example.com ) into numeric IP addresses.

HTTP vs. HTTPS


HTTP sends data in plain text, while HTTPS encrypts data securely using SSL/TLS.
